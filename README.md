> 📑 **Generator gratuit și open-source** de registru de casă pentru asociațiile de proprietari din Republica Moldova. Export PDF și pregătit pentru import în 1C / ERP.

---

## ✨ Funcționalități

- ✅ **Registru de casă complet** — încasări, plăți, sold curent
- ✅ **Export PDF / Print** direct din browser (Ctrl+P → Save as PDF)
- ✅ **100% client-side** — niciun server, zero tracking, datele rămân la tine
- ✅ **Conform Legii 187/2022** privind condominiul în Republica Moldova
- ✅ **Design responsive** — desktop, tabletă, mobil
- ✅ **Zero dependențe** — un singur fișier HTML

## 🚀 Cum folosești

1. Completează **datele asociației** (denumire, perioadă)
2. Adaugă **mișcările de numerar** (încasări și plăți, cu dată și descriere)
3. Soldul se calculează automat
4. Apasă **Export PDF** (sau Ctrl+P) pentru documentul final

Sau pur și simplu deschide [`index.html`](index.html) în browser.
